    AWC | Clase 12, Delegación de Eventos

    ¿Qué es la delegación de eventos en JS?

    La Delegación de Eventos es una técnica avanzada en JavaScript. En lugar de agregar un addEventListener a cada elemento individual, se agrega un solo listener al elemento contenedor. Cuando ocurre un evento en un elemento hijo, este se propaga hacia arriba (burbujeo) hasta llegar al contenedor, donde es capturado y procesado.

    Cuando generamos elementos dinámicamente (como vimos en la práctica en clase), se presenta una situación particular: si agregamos listeners directamente a cada elemento por separado, cada vez que renderizas la lista se crean nuevos listeners. Con el tiempo, se acumulan listeners duplicados. Esto puede general mal rendimiento y posible comportamiento inesperado, además que el código es más complejo y difícil de mantener.

    Cuando efectuamos la delegación de eventos, solemos utilizar la expresión e.target para detectar el elemento donde ocurre el evento, o también: e.target.closest(selector) para encontrar el pariente más cercano que coincida con el selector.

    Otras propiedades comunes relacionadas con .target son: .currentTarget la cual señala al elemento que tiene el listener. También e.relatedTarget señala al elemento relacionado cuando hacemos mouseover / mouseout.

    Métodos forEach() y appendChild()

    El método forEach() sirve para recorrer arrays en JS y ejecutar una función por cada uno de los elementos que componen dicho array. Su expresión es forEach((elemento, indice) => {});

    A diferencia de map(), no devuelve un nuevo array.

    appendChild() nos permite agregar un elemento hijo al final de otro elemento, dentro de un contenedor. Este método agrega el hijo en vivo, si estamos recorriendo un array utilizando el método forEach(), cada elemento es creado individualmente.
