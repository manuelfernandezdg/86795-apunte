    AWC | Clase 11, localStorage y persistencia de datos

    localStorage()

    La propiedad localStorage pertenece al objeto window ue forma parte de la Web Storage API. Es un contenedor de tipo key-value que permite a las aplicaciones cliente guardar datos de forma persistente en el navegador del usuario.

    Tenemos que entender que en localStorage solamente podemos guardar strings o cadenas de texto plano. Por ese motivo utilizamos la notación JSON para guardar nuestros objetos dentro de localStorage

    ¿Cómo funciona?

    Para interactuar con el localStorage lo tenemos que hacer a través de métodos:

    • Para guardar un valor: localStorage.setItem('clave', 'valor');
    • Para obtener un valor: localStorage.getItem('clave');
    • Para eliminar un valor: localStorage.removeItem('clave');
    • Eliminar todo: localStorage.clear()

    Promesas y eventos

    Como Javascript es un lenguaje single-threated, sólo ejecuta una sola cosa por vez. El problema que trae esto es que si tenemos que esperar a la carga de un archivo, o la respuesta de una API, todo el código se bloquea. Para solucionar esta situación, en Javascript utilizamos el modelo de eventos y promesas.

    ¿Qué es una async function?

    Lo que hace la palabra async antes de declarar una función es transformarla en una función asíncrona. Esta función siempre devuelve una promise. Cuando utilizamos await dentro de la función async lo que hacemos es "esperar" por la respuesta antes de continuar con el flujo normal de la carga. Por ejemplo si tenemos la situación const res = await fetch('datos.json') lo que estamos haciendo es pedir que resuelva primero la promise del fetch (la carga de datos) antes de continuar. Es muy común utilizar res como expresión resumida de "response" o "respuesta".

    filter()

    El método filter() sirve para filtrar un array a través de una condición. Siempre devuelve un nuevo array, sin modificar el original.

    Su sintaxis utiliza una función callback, nuevoArray = arrayOriginal.filter(callback);. La función callback lo que hace es analizar (filtrar) cada elemento dentro del array original y devuelve siempre true o false.
