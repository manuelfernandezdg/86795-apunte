    Métodos

    Los métodos son funciones que pertenecen a un objeto. Al ser funciones siempre se ejecutan con paréntesis, por ejemplo getElementById(). Pueden recibir argumentos (parámetros). Generalmente producen un efecto, cambiar algo en el DOM, agregar un evento, modificar un array, entre otros.

    document.querySelector()

    Es un método del objeto document que permite seleccionar un elemento del DOM utilizando un selector CSS.

    Características

    • Devuelve el primer elemento que coincida con el selector.
    • Si no encuentra ningún elemento, devuelve null.
    • Es muy versátil: acepta selectores de clase (.clase), ID (#id), etiquetas (nav), atributos, etc.

    addEventListener()

    Método que permite registrar un evento sobre un elemento del DOM. Cuando ese evento ocurre, se ejecuta una función (callback). Eventos más comunes: click, mouseover, keydown, resize, entre otros.

    getAttribute()

    Método que obtiene el valor de un atributo HTML de un elemento.

    Características

    • Lee el estado actual del elemento a través del nombre del atributo.
    • Siempre devuelve el valor como string (incluso cuando guardamos el valor como true o false)

    setAttribute()

    Método que establece o modifica el valor de un atributo en un elemento HTML.

    Características

    • Aunque pasemos valores tipo booleano como true o false, JS lo convierte siempre a string.
    • Se usa tanto para atributos estándar como para atributos personalizados.

    Scroll y Overflow

    En maquetación llamamos overflow a cuando el contenido desborda su contenedor. Dicho en otras palabras: el contenido es mayor al área de su contenedor padre.

    Este comportamiento está controlado desde CSS con la propiedad overflow. Sirve para decidir qué debe hacer el navegador cuando el contenido "escapa" o "desborda" a su contenedor.

    • overflow: visible es el valor por defecto, el contenido simplemente "desborda" a su contenedor.
    • overflow: hidden corta el contenido, como una máscara de recorte, para no mostrar el desborde.
    • overflow: auto muestra las barras de scroll sólo cuando son necesarias
    • overflow-x / y sirve para controlar el overflow horizontal y vertical.
