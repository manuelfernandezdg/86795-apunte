    Extracción de parámetros de la URL con URLSearchParams

    Cuando navegamos entre páginas dentro de una aplicación web es muy común transferir datos a través de la query string (o cadena de consulta) propia de la URL.

    En una URL pasamos nuestra query string luego del símbolo ?, por ejemplo: detalle.html?id=15.

    Para trabajar con parámetros de la URL utilizamos comunmente:

    • El objeto global window.location que representa la ubicación actual del documento. Contiene información sobre la página que visualizamos.
    • Si queremos saber cuál es la query string (cadena de consulta) actual, tenemos que utilizar window.location.search, la cual devuelve el string posterior al símbolo ?.
    • URLSearchParams es una api nativa de Javascript (ES2015) que nos permite analizar y manipular los parámetros de una URL de forma estructurada. Convierte la query string en un objeto iterable de pares clave-valor.
    • .get(clave) es un método de URLSearchParams el cual devuelve el valor de un parámetro específico. Retorna null si el parámetro no existe.

    En nuestra app, para trabajar la vista de detalle del producto utilizamos:

    1const params = new URLSearchParams(window.location.search);
    2const id = Number(params.get('id'));
    • new URLSearchParams(window.localtion.search); crea una nueva instancia de URLSearchParams pasando como argumento la query string actual, se convierte de esta manera en un objeto que contiene todos los parámetros de la URL.
    • Una vez que params es un objeto podemos buscar a través del método get el id de un artículo en particular. Pero, el problema es que ese id es aún un string.
    • La función Number() convierte dicho string en un valor númerico. Por ejemplo: "15" es ahora 15

    Ejercicio

    Para cada proyecto deben agregar la función de agregar al carrito y mostrar en pantalla los artículos que los usuarios agregaron. Suma si utilizan el localStorage para que la sesión sea persistente

    Además deben agregar la vista de detalle para cada artículo del catálogo. Los campos de la descripción quedan enteramente a elección de uds. Es importante que si tienen acciones como agregar a favoritos y agregar al carrito estas acciones estén presentes también en la vista de detalle.
