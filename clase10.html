    ¿Qué es JSON?

    Javascript Object Notation, es un formato de texto que permite representar datos estructurados. Lo utilizamos a lo largo de muchas aplicaciones, por ejemplo, cuando conectamos a través de APIs. Su tamaño ligero y facilidad para ser leído lo hacen muy útil.

    ¿Cuándo lo usamos? Cuando un servidor web envía información (por ejemplo, una lista de productos, datos de usuario), siempre llega como texto JSON. También lo podemos usar para guardar datos en localStorage dentro del navegador. El trabajo de Javascript es convertir el string de JSON a objeto para poder usarlo luego.

    Trabajo con JSON

    JSON.parse()

    Es un método estático del objeto nativo JSON en JavaScript que analiza (parsea) una cadena de texto con formato JSON válido y la transforma en un valor o estructura de datos de JavaScript (objeto, array, string, number, boolean, null, etc.).

    Lo utilizamos para poder recibir datos de tipo JSON desde un servidor o también desde APIs, para luego convertirlos a objetos que Javascript pueda procesar.

    JSON.stringify()

    El método inverso a parse es JSON.stringify() el cual toma un objeto o valor de Javascript y lo serializa (transforma) en una cadena de texto que sigue el standar JSON.

    Lo utilizamos cuando tenemos que enviar datos al servidor, transformamos con este método el objeto Javascript a una notación que el servidor entiende y puede procesar. También cuando guardamos datos de forma local en el navegador a través del método localStorage(). Sirve también para enviar datos a través de APIs, ya que muhcas esperan recibir dichos datos en formato JSON puro.

    map()

    El método map() crea un nuevo array con los resultados de llamar a una función (callback) por cada elemento del array original.

    • No modifica el array original (es inmutable).
    • Siempre devuelve un nuevo array con la misma cantidad de elementos.

    Cuando utilizamos el método map() para construir un catálogo en HTML vamos a usar la interpolación ${producto.nombre} por ejemplo para llamar a valores que se encuentran dentro del array del producto.

    Es importante también el uso de back ticks `` o tilde invertido, para poder utilizar saltos de línea en la confección del map(), además que el tilde invertido sirve para manejar mejor las interpolaciones con los valores dinámicos.

    Por último, debemos también incluir el método join(), sirve para unir y convertir ese array a un string HTML para ser insertado en el DOM.
