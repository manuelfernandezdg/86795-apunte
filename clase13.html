    Operadores matemáticos en JS

    Los operadores matemáticos (o aritméticos) en JS permiten realizar cálculos numéricos. La mayoría operan con el tipo de dato number.

    • + Suma
    • - Resta
    • * Multiplicación
    • / División
    • % Módulo (resto)
    • ** Exponenciación - potencia (base^exponente)
    1console.log(10 + 5);     // 15
    2console.log(20 - 8);     // 12
    3console.log(4 * 6);      // 24
    4console.log(15 / 3);     // 5
    5console.log(17 % 5);     // 2  (resto)
    6console.log(3 ** 4);     // 81 (3^4)

    Operadores de Incremento y Decremento

    • ++ incremento, donde x++ suma 1 a x
    • -- decremento, donde x-- resta 1 a x

    Diferencia entre prefijo y sufijo

    1let x = 5;
    2 
    3console.log(x++);   // 5  (primero devuelve, luego incrementa)
    4console.log(x);     // 6
    5 
    6console.log(++x);   // 7  (primero incrementa, luego devuelve)

    Operadores de Asignación Aritmética (Compound Assignment)

    • += ej: x += 5 equivale a x = x + 5
    • -= ej: x -= 5 equivale a x = x - 5
    • *= ej: x *= 5 equivale a x = x * 5
    • /= ej: x /= 5 equivale a x = x / 5
    • %= ej: x %= 5 equivale a x = x % 5
    • **= ej: x **= 5 equivale a x = x ** 5
    1let puntos = 10;
    2puntos += 5;     // 15
    3puntos *= 2;     // 30
    4puntos %= 7;     // 2
    5console.log(puntos);

    Precedencia y Agrupación

    1// Sin paréntesis
    2console.log(2 + 3 * 4);     // 14  (primero multiplicación)
    3 
    4// Con paréntesis
    5console.log((2 + 3) * 4);   // 20

    Objeto Math

    • Math.round() Redondea al entero más cercano Math.round(4.7) → 5
    • Math.floor() Redondea hacia abajo Math.floor(4.9) → 4
    • Math.ceil() Redondea hacia arriba Math.ceil(4.1) → 5
    • Math.abs() Valor absoluto Math.abs(-10) → 10
    • Math.sqrt() Raíz cuadrada Math.sqrt(16) → 4
    • Math.pow() Potencia (alternativa a **) Math.pow(2, 3) → 8
    • Math.random() Número aleatorio entre 0 y 1 Math.random()
    • Math.max() / Math.min() máximo / mínimo de varios números Math.max(1,5,3) → 5

    Funciones adicionales

    Number()

    Number() es una función global (también disponible como constructor) que se utiliza para convertir un valor de cualquier tipo a un número (tipo primitivo number). El uso más común de la función Number() es para convertir strings a números. Comúnmente estos strings vienen de un JSON o también desde HTML y tienen que ser modificados para poder operar con ellos dentro de un objeto o también, como valor en una operación matemática.

    1// Uso básico
    2console.log(Number("42"));           // 42
    3console.log(Number("3.14"));         // 3.14
    4console.log(Number(true));           // 1
    5console.log(Number(false));          // 0
    6console.log(Number(null));           // 0
    7console.log(Number(undefined));      // NaN
    8 
    9// Detección de NaN
    10const resultado = Number("hola");
    11console.log(isNaN(resultado));       // true
    12console.log(Number.isNaN(resultado)); // true (método recomendado)

    Métodos y propiedades útiles del objeto Number

    • Number.isInteger(valor) pregunta: ¿es un entero?
    • Number.isFinite(valor) pregunta: ¿es un número finito?
    • Number.isNaN(valor) versión segura de isNaN()
    • Number.parseInt() y Number.parseFloat() también disponibles como funciones globales (parseInt, parseFloat)
