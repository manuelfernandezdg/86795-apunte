    AWC | Clase 7: Position

    CSS Position

    La propiedad position en CSS controla cómo un elemento se posiciona con respecto a la página y también su posición en relación a los demás elementos que componen la maqueta.

    Valores de position:

    • static
    • relative
    • absolute
    • fixed
    • sticky
    • inherit

    position: static

    • El elemento pertenece y sigue de forma normal el flujo de HTML (block, inline, flex, grid)
    • Las propiedades top, right, bottom, left y z-index no tienen efecto.
    • Es el valor que los elementos HTML traen por defecto

    position: relative

    • El elemento mantiene su espacio en el flujo del documento. El documento "guarda" su espacio original en caso de que este modifique su posición en pantalla.
    • Admite las propiedades: top, right, bottom, left y z-index
    • Sirve como contenedor de referencia para aquellos elementos hijos con position: absolute.

    position: absolute

    • Cuando un elemento tiene positición absolute, automáticamente queda removido del flujo normal del documento.
    • Admite las propiedades: top, right, bottom, left y z-index
    • Su posición es respecto al primer ancestro (contenedor padre) que tenga positición relative.
    • Si no hay ningún contenedor que tenga dichos valores, va a utilizar el viewport inicial como punto de refererencia: html o body.

    position: fixed

    • Su posición siempre es en relación a la ventana del navegador (viewport).
    • Admite las propiedades: top, right, bottom, left y z-index
    • Su posición siempre es fija y jamás sigue el scroll normal del documento.

    position: sticky

    • Sigue el flujo normal del documento.
    • El elemento utiliza un valor límite de desplazamiento con respecto a la altura de su contenedor principal.
    • Puede servir para "pegar" los elementos dentro de un contenedor y evitar que el scroll de la pantalla modifique su posición.
    • Tiene una limitación: si el contenedor tiene scroll visible y su altura abandona la pantalla, el elemento va a ser arrastrado por el scroll normal.
